# Ragul Ramesh - Personal Portfolio

A modern, high-performance personal portfolio website built with semantic HTML5, modern CSS3, and JavaScript.

## 🚀 Live Demo
- [Live Portfolio Preview](https://ragulramesh300-gma.github.io/Ragul_Ramesh_Portfolio/)

## 🛠 Tech Stack
- **HTML5**: Semantic markup, accessible structure, SEO metadata
- **CSS3**: Modern White Light Theme, CSS Grid, Flexbox, glassmorphism, responsive breakpoints
- **JavaScript (Vanilla)**: Smooth scroll interactions, dynamic typing effect, bento counters, project category filters, card tilt physics
- **Typography**: Plus Jakarta Sans (via Google Fonts CDN)

## 📁 Project Structure
```text
├── index.html                           # Portfolio markup & sections
├── style.css                            # Modern styling & design system
├── script.js                            # Interactive animations & filtering
├── photo.jpg                            # Professional hero portrait image
├── Resume_V2.pdf                        # Resume file
└── Work_Report_Ragul_Ramesh_Updated_v3.pdf # Work report document
```

## 💻 Local Development
Simply open `index.html` in your browser or run a lightweight local HTTP server:

```bash
# Python
python -m http.server 8000

# Node (npx)
npx serve
```
